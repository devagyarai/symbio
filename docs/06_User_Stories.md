# User Stories

## Administration & Security
- **As an Admin**, I want to invite users to my organization and assign them roles so that they can access the platform securely.
- **As an Admin**, I want to view an audit log of all activities so that I can maintain compliance and security.
- **As an Admin**, I want to manage organization-wide settings (e.g., name, billing) so that the workspace reflects our current status.

## Project & Task Management
- **As a Manager**, I want to create a new project and assign tasks to members so that we can track our deliverables.
- **As a Manager**, I want to view project analytics and progress charts so that I can identify bottlenecks.
- **As a Member**, I want to update the status of my tasks via a Kanban board so that the team knows my progress.
- **As a Viewer**, I want to browse project boards in read-only mode so that I stay informed without altering data.

## Collaboration & Real-Time Updates
- **As a Member**, I want to receive real-time notifications when I am mentioned or assigned a task so that I don't miss important updates.
- **As a Member**, I want to upload files and attachments to a task so that my team can review my work.
- **As a Member**, I want to add comments to a task and see others typing in real-time so that we can resolve issues quickly without leaving the app.

## User Experience
- **As a User (All Roles)**, I want to toggle Dark Mode so that I can reduce eye strain during late-night work sessions.
- **As a User (All Roles)**, I want to manage my personal profile and avatar so that my team can easily identify me.
