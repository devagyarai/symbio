# User Personas

## Alice (The Admin)
- **Role:** IT Manager or Founder.
- **Goals:** Secure the organization's data, manage billing, onboard users, and configure role assignments.
- **Pain Points:** Hard to track who has access to what, lacking visibility into org-wide activities.
- **Key Features Used:** Organization settings, Member directory, Audit logs, RBAC management.

## Bob (The Manager)
- **Role:** Project Leader / Department Head.
- **Goals:** Execute projects efficiently, assign tasks to the right team members, and monitor progress.
- **Pain Points:** Context switching between task managers and chat apps, losing track of task statuses.
- **Key Features Used:** Project dashboards, Kanban boards, Task assignment, Analytics.

## Charlie (The Member)
- **Role:** Individual Contributor / Team Member.
- **Goals:** Understand what needs to be done, collaborate with peers, and deliver work on time.
- **Pain Points:** Missing important updates, struggling to find attached files or context for a task.
- **Key Features Used:** My Tasks view, Task details, File uploads, Real-time comments, Notifications.

## Diana (The Viewer)
- **Role:** Stakeholder or Client.
- **Goals:** Check on project progress without accidentally breaking anything.
- **Pain Points:** Getting overwhelmed by too much information or having to ask for manual status updates.
- **Key Features Used:** Read-only Project dashboards, Task status views.
